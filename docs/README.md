# XGenius documentation

This folder keeps the project **aligned, auditable, and easy to hand off** (humans and assistants). Read this index first.

| File | Purpose |
|------|--------|
| [GOALS.md](GOALS.md) | What we are building and why (World Cup–first). |
| [EXPECTATIONS.md](EXPECTATIONS.md) | Quality bar, scope rules, and “done” criteria. |
| [PHASES.md](PHASES.md) | Phased delivery plan and **current status**. |
| [AUDIT-LOG.md](AUDIT-LOG.md) | Dated check-ins: what was verified and what to fix next. |
| [AGENT-CONTEXT.md](AGENT-CONTEXT.md) | Constraints and conventions for contributors and AI helpers. |
| [DECISIONS.md](DECISIONS.md) | Notable technical choices (short, living log). |

**When to update**

- After each phase: **PHASES.md** and a new row in **AUDIT-LOG.md**
- When scope or quality bar changes: **EXPECTATIONS.md**
- When product direction shifts: **GOALS.md**
- When we lock in an approach: **DECISIONS.md**
